# 아이디어 소개서 — 주요기능과 특징, 기대효과 (요약본)

분야: AI 및 빅데이터

## ■ 주요 기능과 특징

**1. AI 기반 무장애 빅데이터 구축**
- 경주·전주·강릉·서울·부산의 장소 10,196곳, 후기 27,047건 수집
- 광고성 후기 제거(23,351건) → 장소와 연결(1,550곳)
- 접근성 언급 702곳을 생성형 AI가 판정해 근거가 확인된 387곳 데이터화 (경산 47곳 별도)
- 10,196곳 → 1,550곳 → 702곳 → 387곳

**2. 설명 가능한 AI (환각 방지)**
- 모든 판정에 원문 근거 문장 첨부, 코드로 원문 대조 (388건 중 387건 일치)
- 근거가 없으면 추측하지 않고 '미확인' 처리

**3. 데이터 체계화**
- 장소별 판정·근거 유형·엘리베이터·장애인 화장실·주차·주의사항을 표준 형식으로 정리
- 방문 후기와 업체 표기를 구분해 신뢰도 표시
- '불가' 23곳 중 22곳은 방문 후기에서만 확인 → 실제 이용자 후기가 핵심 데이터

**4. 이동유형별 AI 추천 동선**
- 휠체어·노약자·시각장애 등 이동유형에 맞춰 근거가 확인된 장소로만 일정 구성
- 화장실·교통약자 이동지원·할인 정보·음성 안내 제공

## ■ 기대효과
- **이동약자:** 방문 전에 근거와 함께 접근 가능 여부를 확인해 현장 실패 감소
- **지자체:** 접근 불가 장소와 정보 공백을 수치로 제시 → 개선 우선순위 자료 (경산 확인 비율 약 6%)
- **확장성:** 같은 절차로 다른 지역에 적용, 공공데이터와 결합해 확장

## 제출 전 확인
- 정확도(판정이 맞는지)는 아직 사람 검증 전 → 30곳 대조 후 수치 추가 권장
- 4번의 노약자·시각장애는 구현 진행 중
- 경산 비율: 앱 카드(38곳·5%)와 이 문서(47곳·6%) 기준 통일 필요
