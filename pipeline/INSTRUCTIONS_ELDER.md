# 노약자·시각장애 판정 작업 (청크 파일 1개 담당)

입력: chunk_*.json (장소 배열, 각 {id,name,cat,unit,addr,docs:[{u,d,t}]}). docs[].t 는 블로그 스니펫(최대 280자).

각 장소에 대해, 스니펫에 쓰인 사실만으로 두 가지를 판정한다.

## A. 노약자 (고령자·보행보조기·걷기 힘든 사람) 기준 elder
- 가능: 엘리베이터 있음, 계단 없음/턱 없음, 평지·완만, 경사로, 휠체어 대여, 쉴 곳/좌석 여유 등 걷기 부담이 적다는 서술이 이 장소에 대해 있음
- 부분: 편한 점과 부담(가파른 길, 일부 계단, 긴 도보, 2층 화장실 등)이 함께 있음
- 불가: 계단만 있음, 엘리베이터 없이 2층 이상, 가파른 언덕길로만 진입 등
- 미확인: 판단할 서술 없음
## B. 시각장애 동반 기준 visual
- 가능/있음: 점자블록, 점자 안내, 음성 안내, 안내견 동반 가능, 촉지도, 오디오 가이드, 직원 안내 서비스 등이 이 장소에 대해 서술됨
- 제약: 안내견 거부, 어둡고 복잡한 동선 등 명확한 불편 서술 → "부분" 또는 "불가"
- 서술 없으면 반드시 "미확인" (휠체어 정보로 추정 금지)

## 규칙
- 추정 금지. 스니펫이 여러 장소 나열이라 불확실하면 미확인.
- 각 판정의 quote 는 스니펫 원문에서 글자 그대로 복사한 40자 이내 구절. 없으면 null (그 경우 판정은 미확인).
- note 는 20~50자 한국어 요약 (원문 복붙 금지).

## 출력: 같은 폴더 elder_<chunk_ 뺀 파일이름>.json (JSON 배열, 입력 순서, 모든 id)
{"id":"...","elder":"가능|부분|불가|미확인","elder_quote":"..."|null,"elder_note":"..."|null,
 "visual":"가능|부분|불가|미확인","visual_quote":"..."|null,"visual_note":"..."|null}

파일을 끝까지 읽고 판단한 뒤 python 으로 저장하고, json.load 로 개수가 입력과 같은지 확인하라. 다른 파일은 건드리지 마라. 마지막 답변은 "파일명, 개수, elder 분포, visual 분포" 한 줄.
